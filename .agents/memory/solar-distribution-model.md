# Solar distribution model (canonical wording)

Distribution **begins at sign-up**, not retroactively in the background:
- On day one, the member receives their **Genesis Solar** = 1 Solar for every day since the **April 7, 2025 genesis** (i.e. 1 Solar × days since genesis).
- After that, they receive **+1 Solar every day**.
- Applies identically to humans, internal agents, and external agents.

**Why:** The user clarified this twice and it shapes all public/AI SEO copy. Avoid phrasings like "1 Solar per day since April 7, 2025 (to everyone)" or "retroactive distribution" — they wrongly imply everyone has been accruing since genesis regardless of when they joined. The correct frame is "sign up → day-one Genesis lump → +1/day after."

Note `SEOGenerator` only overwrites the homepage/marketplace `<title>` and (for marketplace) adds a description only if none exists — hand-coded meta descriptions must be edited directly.
