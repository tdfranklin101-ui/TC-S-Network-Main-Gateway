# TC-S Voucher Module - Complete Documentation

## Overview

The Voucher Module enables digital vouchers for physical goods, services, and experiences within the TC-S marketplace. Vouchers bridge the digital economy (Solar) with physical-world redemption while maintaining energy-based pricing and human-in-loop safety.

## Module Components

### 1. Database Models (`voucher_models.py`)

**Tables:**

- `voucher_listings` - Marketplace listings for vouchers
- `vouchers` - Individual purchased voucher instances
- `voucher_redemptions` - Audit log of redemption attempts
- `vendor_voucher_settings` - Vendor preferences

**Key Features:**

- Separate listing (template) from instances (purchased vouchers)
- Each voucher has unique code (e.g., TC-8F3D2A)
- Complete audit trail
- Flexible metadata (JSON fields)

### 2. Business Logic (`voucher_service.py`)

**Core Methods:**

**Listing Management:**

```python
await service.create_listing(...)  # Returns proposal
await service.approve_listing(proposal)  # Creates actual listing
```

**Purchase Flow:**

```python
await service.purchase_voucher(...)  # Returns proposal
await service.approve_purchase(proposal)  # Creates vouchers, processes payment
```

**Redemption Flow:**

```python
await service.validate_redemption(...)  # Check if voucher valid
await service.approve_redemption(...)  # Mark as redeemed
```

**Search & Query:**

```python
service.search_listings(...)  # Find available vouchers
service.get_user_vouchers(...)  # User's purchased vouchers
service.get_vendor_vouchers(...)  # Vendor's sales
```

### 3. REST API (`voucher_api.py`)

**Endpoints:**

```
POST   /api/vouchers/listings/create      # Vendor creates listing
POST   /api/vouchers/listings/approve     # Vendor approves proposal
GET    /api/vouchers/listings/{id}        # Get listing details
GET    /api/vouchers/listings/vendor/{id} # Vendor's listings

POST   /api/vouchers/purchase              # Buyer initiates purchase
POST   /api/vouchers/purchase/approve      # Buyer approves purchase

POST   /api/vouchers/redeem/validate       # Vendor validates voucher
POST   /api/vouchers/redeem/approve        # Vendor confirms redemption

POST   /api/vouchers/search                # Search listings
GET    /api/vouchers/my-vouchers           # Buyer's vouchers
GET    /api/vouchers/vendor/sales          # Vendor's sales
```

### 4. UI Components (`voucher_components.jsx`)

**React Components:**

- `CreateVoucherListing` - Vendor creates/manages listings
- `PurchaseVoucher` - Buyer purchases vouchers
- `MyVouchers` - Buyer views owned vouchers
- `RedeemVoucher` - Vendor scans and redeems

## Human-in-Loop Safety Gates

### Gate 1: Listing Creation

**Who:** Vendor  
**When:** Before listing is published  
**What:** Review pricing, energy calculation, ethics score  
**Why:** Prevent mispriced or problematic offerings

### Gate 2: Purchase

**Who:** Buyer  
**When:** Before payment processed  
**What:** Review total cost, expiration, redemption details  
**Why:** Prevent accidental purchases or buyer confusion

### Gate 3: Redemption

**Who:** Vendor  
**When:** Before voucher marked as used  
**What:** Verify voucher valid, customer present, item can be fulfilled  
**Why:** Prevent fraud, ensure legitimate redemptions

## Security Considerations

1. **Voucher Code Security:**
- Cryptographically random codes
- One-time use enforcement
- Rate limiting on validation attempts
1. **Vendor Verification:**
- Only authorized vendor can redeem their vouchers
- Location validation (optional)
- Device fingerprinting
1. **Fraud Prevention:**
- Redemption logs (immutable)
- Suspicious pattern detection
- Manual review for high-value vouchers
1. **Privacy:**
- Buyer identity only revealed to vendor at redemption
- Anonymized analytics
- GDPR compliance

## Support & Maintenance

**Common Issues:**

**“Voucher won’t scan”**
→ Manual code entry always available
→ Check QR code image quality
→ Verify redemption window not passed

**“Says voucher already redeemed”**
→ Check redemption log
→ Verify with vendor
→ Dispute resolution process

**“Vendor can’t redeem”**
→ Verify vendor ID matches
→ Check vendor settings
→ Ensure redemption within valid window
