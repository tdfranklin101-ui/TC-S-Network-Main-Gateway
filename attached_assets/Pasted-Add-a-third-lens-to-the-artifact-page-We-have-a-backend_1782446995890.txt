Critical behavior rules (do not violate):

This lens is ADVISORY — the human decides. Never use it to auto-block, hide, or reject an artifact based on its band/score. Bands are: abundant (best), aligned, consider, strained.
The ONLY hard block is abundance_lens.blocked === true (mandated prohibited content). When that's true, this is the signal the existing Sign Off Kid Solar shut-off switch acts on — wire the block to that switch, and show the deny reason from abundance_lens.gate.reason.
approved already means "not hard-denied" — don't add your own gating on top of recommended or band.
Where it goes: render a new card immediately after the ROB LOW DECISION LENS card on the artifact page, matching the existing dark lens-card styling. It pairs with (does not replace) the human-needs lens.

Drop-in renderer (adapt to your component framework; or just print uim_metric.rendered_text for a no-markup version):

function renderAbundanceLens(lens) {
  if (!lens) return '';
  if (lens.blocked) {
    return `
      <section class="lens-card lens-deny">
        <h3>🛑 ENERGETIC-ETHICAL ABUNDANCE LENS</h3>
        <p><strong>Hard-deny:</strong> ${lens.gate?.reason ?? 'Prohibited content.'}</p>
        <p>Use the Sign Off Kid Solar shut-off switch on this item.</p>
      </section>`;
  }
  const bandColor = { abundant:'#34d399', aligned:'#60a5fa', consider:'#fbbf24', strained:'#f87171' }[lens.band] || '#9ca3af';
  const status = lens.recommended ? 'Recommended' : 'Advisory — your choice';
  return `
    <section class="lens-card">
      <h3>♻️ ENERGETIC-ETHICAL ABUNDANCE LENS</h3>
      <p style="color:${bandColor}"><strong>${lens.band.toUpperCase()}</strong>
         · ${(lens.abundance_score * 100).toFixed(0)}/100 · ${status}</p>
      <p>${lens.band_meaning}</p>
      <ul>${(lens.insights || []).map(i => `<li>${i}</li>`).join('')}</ul>
      ${lens.remediation?.text ? `<p>↦ ${lens.remediation.text}</p>` : ''}
      <p class="muted">Advisory guidance paired with the human-needs analysis. The choice is yours.</p>
    </section>`;
}
// usage: container.insertAdjacentHTML('beforeend', renderAbundanceLens(uimMetric.abundance_lens));
