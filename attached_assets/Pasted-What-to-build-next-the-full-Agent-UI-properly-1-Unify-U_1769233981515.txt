The 5 missing components, clarified into concrete deliverables

(1) Security Headers Update (required)

Deliverable: update all admin/agent fetch calls to include:
	•	X-Req-Id: <uuid> (per request)
	•	existing auth (X-Session-Token or Authorization: Bearer)
	•	(only for S2S) X-Admin=true, X-Admin-Key server-side only (never from browser)

Also add:
	•	a tiny reqId() helper + fetchWithAuth() wrapper used everywhere.

(2) Scheduler Dashboard

Deliverables:
	•	GET /api/schedulers → list jobs (name, status, last_run, next_run, last_result)
	•	POST /api/schedulers/:job/trigger → manual run
	•	UI table with:
	•	Job name
	•	Status chip
	•	Last run / Next run
	•	“Trigger” button (RBAC protected)
	•	“View runs” drawer

If you don’t have scheduler endpoints yet, you still build the UI shell and wire it once the endpoints exist.

(3) Intent Log Viewer (Audit Trail)

Deliverables:
	•	GET /api/audit?user=&action=&from=&to=&limit=&cursor=
	•	UI:
	•	Filters (user, action type, date range)
	•	List view (timestamp, actor, action_type, entity_ref, payload_hash)
	•	Detail drawer: request id, payload hashes, status, approvals
	•	Export button (CSV)

(4) RBAC-aware UI

Deliverables:
	•	A GET /api/me endpoint that returns:
	•	member_id, roles, network_id, permissions (optional expanded)
	•	Frontend gating:
	•	Member: marketplace only
	•	Commissioner admin: pricing + settlement views
	•	TCS admin: all tabs + action execution

This is mostly UI logic + hiding routes; the backend must still enforce everything.

(5) Marketplace Admin Panel

Deliverables:
	•	Draft Review: assets/listings pending moderation or pending publish
	•	Price Publish: approve/publish price quotes
	•	Settlement History: daily runs + drilldown
	•	Controls:
	•	category rules (floors/ceilings)
	•	microfee settings
	•	tax-inclusive config (always on, but show it)

Minimum endpoints typically needed:
	•	GET /api/admin/assets?status=draft|flagged
	•	POST /api/admin/assets/:id/approve
	•	POST /api/pricing/:listing_id/publish
	•	GET /api/admin/settlements
	•	GET /api/admin/settlements/:id
