TASK 6 — ORCHESTRATOR LOOP
============================================================

Create:

server/orchestrator/tcs-frontier-orchestrator.js

Implement this deterministic shell around the model:

1. receive authenticated intent
2. assign task_id
3. GET /api/uim/system
4. GET /api/uim/capabilities
5. retrieve relevant /api/uim/network-knowledge
6. build ORCHESTRATION_TASK_V1
7. ask frontier model for ORCHESTRATION_PLAN_V1 JSON
8. parse strictly
9. POST plan to /api/uim/plan/validate
10. if INVALID:
       return validator findings to model
       request revised plan
11. repeat up to 5 revisions
12. if REQUIRES_APPROVAL:
       stop and return WAITING_APPROVAL
13. if VALID:
       invoke each step only through /api/uim/invoke
14. poll async requests through status endpoint
15. collect authoritative results
16. if step fails:
       allow model to revise remaining plan
       revised plan must be validated again
17. verify requested outcome deterministically
18. retrieve workflow/provenance records
19. return final structured result

The model must never be allowed to say:

"success"

unless TC-S verification confirms success.
